> 🔍 Interact with your PDF documents using natural language!  
> QueryPDF uses OpenAI's GPT models and LangChain to turn your documents into intelligent chat partners.

---

## 🚀 Features

- 🧠 Chat with your PDFs like a human
- 🗂️ Upload and interact with multiple documents
- ⚙️ Powered by OpenAI GPT & LangChain
- 🛠️ Built with Streamlit for quick deployment
- 🔐 Secure local file processing (optional cloud integration)

---

## 📦 Tech Stack

- **Frontend**: Streamlit
- **Backend**: Python, LangChain
- **LLM**: OpenAI GPT
- **Embedding Models**: OpenAI / HuggingFace
- **Vector DB**: FAISS / ChromaDB
